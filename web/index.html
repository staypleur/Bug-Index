VS Code 연결.

터미널의 오류를 나만의 도감에 자동으로 기록하세요.

01 / 확장 설치

저장소의 extension 폴더에서 확장을 패키징해 VS Code에 설치하세요. 설치 방법은 README에 안내되어 있습니다.

02 / 수집 토큰 발급

토큰은 한 번만 표시됩니다. VS Code의 Bug Index: Connect 명령에 입력하세요. 비밀번호처럼 보관하세요.

복사한 뒤 이 화면을 벗어나면 다시 볼 수 없습니다.

03 / 자동 수집 켜기

명령 팔레트에서 Bug Index: Enable Collection을 실행하세요. 지원되는 셸의 터미널에서 실행한 C, Python, Java 오류가 수집됩니다. 터미널 셸 통합이 필요합니다.

전송 전 알려진 비밀 값과 사용자 홈 경로를 마스킹합니다. 민감한 프로젝트에서는 수집을 꺼주세요.
