# Bug Index

개발 중 만난 오류를 자동으로 수집하고, 해결 경험을 쌓아 성장시키는 버그 도감 서비스입니다.

## 확정된 첫 출시 범위

- 여러 사용자가 가입해서 사용하는 서비스
- C, Python, Java 오류 수집
- VS Code 연동부터 제공
- 자동 오류 수집, 분류, fingerprint 기반 재발 판별
- 버그 도감, 검색, 원인·해결 방법·학습 기록
- 같은 버그를 반복해서 만나면 버그 경험치와 레벨 상승
- 레벨이 높아질수록 다음 레벨에 필요한 경험치 증가
- 무료 기본 기능과 월 구독 구조
- 유료 기능: 고급 통계와 랭킹 조회

## 아직 결정하지 않은 사항

- 경험치를 오류 종류 전체에 합산할지, fingerprint별 개별 버그에 부여할지
- 경험치 곡선과 랭킹 점수, 반복 발생 악용 방지 기준
- 로그인 방식
- 월 구독 가격, 실제 결제 연동 시점
- 첫 배포 환경: 무료 클라우드 또는 사용자 소유 Mac mini
- 구체적인 UI 스타일

## 구현 방향

구현 기술은 개발 담당자에게 위임되었습니다. 데이터 내보내기와 환경 변수 설정을 통해
개발 환경, 무료 호스팅, 유료 호스팅 및 Mac mini 사이의 이전이 가능하도록 설계합니다.
세부 기술 구성은 구현 시 문서화합니다.

오류 로그에 포함될 수 있는 비밀 정보는 서버 전송 전에 마스킹해야 합니다.
사용자별 수집 기록은 접근 권한을 분리하고, 랭킹에는 원본 로그나 소스 코드를 노출하지 않습니다.

## 개발 상태

요구사항 정리 단계입니다. 실행 가능한 애플리케이션과 배포는 아직 제공되지 않습니다.
